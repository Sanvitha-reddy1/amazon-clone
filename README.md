# 🛒 Amazon Clone (UI Only)

A responsive Amazon homepage clone built using **HTML5** and **CSS3**.

This project focuses on layout structuring, styling, and responsive design without using any JavaScript.

---

## 🚀 Live Demo

(You can deploy later using GitHub Pages and paste the link here)

---

## 📌 Features

* Responsive navigation bar
* Hero section with promotional banner
* Product category sections
* Grid-based product layout
* Footer with multiple columns
* Mobile responsive design using Flexbox and CSS Grid

---

## 🛠️ Tech Stack

* HTML5
* CSS3
* Flexbox
* CSS Grid
* Media Queries

---

## 📱 Responsiveness

The layout adjusts for:

* Desktop screens
* Tablets
* Mobile devices

Media queries are used to modify layout structure and alignment based on screen width.

---

## 🎯 Purpose of This Project

This project was built to strengthen:

* HTML structure understanding
* CSS layout mastery
* Flexbox & Grid concepts
* Responsive design skills

It is a frontend UI project and does not include backend functionality.
